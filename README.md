## About these recipes

- **Two ways to measure.** Each ingredient lists volume measurements with weight/fluid ounces in parentheses where it's practical, so scale-cookers and cup-cookers can both follow along.
- **Single-pan where possible.** The emphasis is on weeknight-simple cooking with minimal cleanup.
- **Iowa-rooted.** Pork, sweet corn, and dairy show up a lot here on purpose.

## Contributing
