# Recipes

A small, growing collection of personal recipes by **Joshua Walderbach**.

Midwest comfort food, mostly — simple to make, honest ingredients, and written so you can cook by volume (cups, teaspoons) **or** by weight (ounces), whichever you prefer.

## About these recipes

- **Two ways to measure.** Each ingredient lists volume measurements with weight/fluid ounces in parentheses where it's practical, so scale-cookers and cup-cookers can both follow along.
- **Single-pan where possible.** The emphasis is on weeknight-simple cooking with minimal cleanup.
- **Iowa-rooted.** Pork, sweet corn, and dairy show up a lot here on purpose.

## Contributing

This is a personal recipe collection. To add a new recipe, drop a new `.md` file in the repo root following the format of the existing ones (description, ingredients, instructions, swaps & tips) and add a row to the table above.
